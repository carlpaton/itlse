Onboarding

Build out the company hierarchy — companies, divisions, contracts, and sites — that the rest of AoTech is organised around.

DEV NOTES

  • This is a clickable prototype only — nothing is persisted. Refreshing the page resets the hierarchy back to the seed data below.
  • Each level only captures a name for now; a GUID is generated on creation to stand in for the eventual record ID. Other fields (contacts, addresses, contract dates, etc.) will follow once the data model is agreed.
  • Sites onboarded here represent the same entity used across Sites and Assets. Once this flow is wired up, the existing site onboarding screens will be adapted to create sites under a Contract from this hierarchy instead of standalone.
  • A Company can have many Divisions, a Division can have many Contracts, and a Contract can have many Sites.
