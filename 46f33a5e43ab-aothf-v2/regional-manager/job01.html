DEV NOTES

  • Scan QR code speeds up the populating of most of the fields when creating a job. fields excluded from this are fault and work description
  • Job # - the user can accept the auto incremeting default or change to be something else, the number will always increment for the next job
  • Company - this is a search box, the user can select a result from the existing or click create new when not found, this adds a blank company with just the name set. Company is the company that owns the asset.
  • Model # and Serial # are search fields to lookup the asset the job is attached to
  • Assigned company - assigned company is a drop down of all contractor companies onboarded with a client, if not found they can add on the fly the same as Company
  • Photos are displayed here, max 5, with an option to add a new photo or delete an existing one
